      链路状态

      画面来自板载 OV2640（DVP 并口，XCLK=GPIO15 / PCLK=GPIO13 / D0-D7=GPIO11,9,8,10,12,18,17,16）， 板端直接输出 JPEG，base64 内联后复用既有上行链路（USB 串口 / WiFi）上报， 服务端再以 MJPEG 转发给浏览器。
      不需要给板子写 HTTP 服务：板子始终是客户端，服务端连不上它，所以画面是「推」上来的； 这也意味着拔掉 USB 走 WiFi 时同一套逻辑照样成立。
